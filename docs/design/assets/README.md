# Cassette design assets

`casette_retro.png` is the exact 1080×1080 PNG supplied by the user on 22 October 2026. It is preserved byte-for-byte, including its background and framing.

`cassette-icon.png` is the current 1024×1024 opaque production icon, identical to the app AppIcon asset and used by README. Both app and extension use the same 64×64 derived widget mark. No recoloring, cropping, AI regeneration or redesign was applied. The previous `retro-rainbow-cassette-original.png` and `frosted-rainbow-cassette-original.png` remain preserved as historical designer sources.

The original pre-rebrand icon/renderer and `widget-selected-concept.png` remain historical user design references. They are not current branding and are not bundled as sample music or artwork. See [Cassette widgets and branding](../cassette-widgets.md).

The earlier `frosted-rainbow-cassette-original.png` remains only as the superseded designer source. Active asset catalogs, README and current widget captures use the latest retro artwork.
